# Deckforge development contract

This is an original smoke starter and two architecture/planning documents, not a completed application.
The documentation marks current commands separately from future contracts.
Do not assume npm-installed or sandbox-only tools exist on the user's machine.
Use the pinned prototype dependency first. Upgrade only with the same tests and rendered fixture.
No network or model provider is required by the smoke fixture.
No auto-discovery of private company documents. No uploading sources to a provider without a configured policy.
Never overwrite manually edited customer PPTX files. Keep upstream checkouts outside this repository.
Treat fonts as local/user-supplied. Do not commit or distribute font binaries.
